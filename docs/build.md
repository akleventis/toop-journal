# Project Build Structure

## Packaged App Structure

```
build/macos-arm64/Book of Toop.app/
└── Contents/
    ├── Info.plist
    ├── MacOS/
    │   ├── bun                    # Bun runtime
    │   ├── launcher               # Electrobun launcher
    │   ├── libasar.dylib
    │   └── libNativeWrapper.dylib
    └── Resources/
        ├── app/
        │   ├── bun/
        │   │   └── index.js       # Bundled bun process
        │   └── views/
        │       └── mainview/
        │           ├── index.html
        │           ├── index.js   # Webview shim
        │           ├── renderer.js
        │           ├── renderer.css
        │           └── tailwind.css
        ├── main.js
        └── version.json
```

## Source → Build Mapping

| Source | Built output |
|---|---|
| `src/bun/index.ts` | `app/bun/index.js` (bundled by Bun) |
| `src/mainview/index.ts` | `app/views/mainview/index.js` (bundled by Bun) |
| `src/mainview/index.html` | `app/views/mainview/index.html` (copied) |
| `src/mainview/renderer.js` | `app/views/mainview/renderer.js` (copied — built by esbuild) |
| `src/mainview/renderer.css` | `app/views/mainview/renderer.css` (copied) |
| `src/mainview/tailwind.css` | `app/views/mainview/tailwind.css` (copied) |

`renderer.js`, `renderer.css`, and `tailwind.css` are gitignored build artifacts generated by `npm run build:assets` before the Electrobun build runs.

## Build Commands

```bash
npm run build:assets   # esbuild renderer + tailwindcss
npm run build          # build:assets + electrobun build → build/
npm run package        # build + package into DMG
```

## User Data Location

**Production** (`npm run build` / packaged app):
```
~/Library/Application Support/com.bookoftoop.app/stable/
├── journal.db          # SQLite database
├── masterIndex.json    # Cloud sync master index
├── config.json         # AWS credentials (gitignored)
├── backups/            # Daily DB backups
└── logs/               # Daily log files
```

**Development** (`npm run dev`):
```
~/Library/Application Support/com.bookoftoop.app/dev/
```

`Utils.paths.userData` from `electrobun/bun` returns the correct path automatically via the `channel` field in `version.json` — no manual check required.

> **First-time packaged launch:** no data exists at `stable/` yet. Manually copy your DB and config from the old Electron location (`~/Library/Application Support/Book of Toop/`) if migrating.

## Development vs Production

| Resource | Development | Production |
|---|---|---|
| userData | `com.bookoftoop.app/dev/` | `com.bookoftoop.app/stable/` |
| Database | `dev/journal.db` | `stable/journal.db` |
| Renderer | esbuild one-shot build | pre-built, copied into app bundle |
| WebKit | System WebKit | System WebKit |
